# AI-Based Missing Child Identification System

## Project Overview
This project is an AI-based web application designed to help identify missing children using face recognition techniques. Users can upload an image, and the system compares it with stored images in a database to find possible matches.

## Problem Statement
Many children go missing every year and manual identification is slow and error-prone. This project provides a technology-driven solution using Artificial Intelligence.

## Features
- Upload image
- Compare with stored images
- Display match found / not found
- Simple web interface

## Technology Stack
- Python
- Flask
- face_recognition
- NumPy
